# Landing-Page-Barbearia
Projeto prático de front-end com foco em responsividade e experiência do usuário. Landing page para curso de barbearia desenvolvida utilizando HTML5, CSS3 e JavaScript.

##Sobre o projeto
Esta é uma landing page desenvolvida como projeto de portfólio, voltada para divulgar um **curso de barbearia para iniciantes**.  
O objetivo é demonstrar conhecimentos em **HTML, CSS e JavaScript**, além de boas práticas de desenvolvimento front-end.

---

##Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript
- Git & GitHub (versionamento)
- GitHub Pages (deploy online)

---

##Funcionalidades
- Layout responsivo para desktop e mobile  
- Menu de navegação funcional com âncoras  
- Seções: Início, Sobre o curso, Avaliações de clientes, Produto/Curso  
- Botões e links interativos  
- Formulário de contato (visual, sem backend)
